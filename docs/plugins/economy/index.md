# Economy

The economy plugins provide player-facing buying and selling through Server Assist.

| Plugin | Model | What it adds |
|---|---|---|
| [Admin Shop](admin-shop.md) | GUI hook | Item sales plus permanent and temporary permission products for dukes |
| [Auction House](auction-house.md) | Provider with panel fallback | Player listings, buyout purchases, fees and admin controls |

Both are server-only. They use the Server Assist client only for rendering and enforce all prices, ownership and payment checks on the server.
