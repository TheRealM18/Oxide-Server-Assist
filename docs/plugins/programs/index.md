# Programs

Programs are standalone services and tools. They do not load as Oxide plugins or client mods.

| Program | What it does |
|---|---|
| [QLN Pack Server](qln-pack-server.md) | Serves the client mod pack, manifest and signed archives |
| [MediaRelay](media-relay.md) | Media Integration relay for Twitch EventSub, custom webhooks and queued events |
| [TwitchRelay](twitch-relay.md) | Legacy Twitch-only relay |

Programs can run on a different host from the game server when the network and configuration allow it.
