# Server utilities

Utility plugins cover plugin development, Twitch integration and multi-server networking.

| Plugin | What it adds |
|---|---|
| [Plugin Hot Reload](plugin-hot-reload.md) | Watches `.cs` files and reloads Oxide plugins with filters, history and commands |
| [Twitch Integration](twitch-integration.md) | Twitch linking, tiers, loadouts and viewer-triggered effects |
| [BuggeeNet](buggee-net.md) | Redis-backed server registry, redirects and shared player state |

Plugin Hot Reload and Twitch Integration expose optional Server Assist panels. BuggeeNet adds a fleet/travel panel and also works through chat commands.
