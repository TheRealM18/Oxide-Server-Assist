# Server utilities

Utility plugins cover plugin development, media/streaming integration and multi-server networking.

| Plugin | What it adds |
|---|---|
| [Plugin Hot Reload](plugin-hot-reload.md) | Watches `.cs` files and reloads Oxide plugins with filters, history and commands |
| [Media Integration](media-integration.md) | Platform-neutral media rewards: Twitch today, custom webhooks, more providers planned |
| [Twitch Integration](twitch-integration.md) | Legacy Twitch-only implementation and rollback path |
| [BuggeeNet](buggee-net.md) | Redis-backed server registry, redirects and shared player state |

Plugin Hot Reload, Media Integration and Twitch Integration expose optional Server Assist panels. BuggeeNet adds a fleet/travel panel and also works through chat commands.
