# Administration

Administration plugins add staff tooling without requiring separate client mods. Their interfaces render through Server Assist.

| Plugin | What it adds |
|---|---|
| [PermissionGui](permission-gui.md) | Groups, users, tracks, defaults and a searchable permission/command browser |
| [AdminSuite](admin-suite.md) | Player moderation, teleports, inventory tools, world controls, logs, snapshots and rollback |
| [AdminKits](admin-kits.md) | Item kits with exact saved item data, cooldowns, limits and per-kit permissions |

All three plugins are server-only. Install them in `oxide/plugins`, grant their permission nodes, and open their cards in the Server Assist Home board.
