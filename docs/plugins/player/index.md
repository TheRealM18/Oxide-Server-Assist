# Player features

Player-facing plugins add rewards, storage, profiles and voting.

| Plugin | What it adds |
|---|---|
| [Daily Rewards](daily-rewards.md) | Daily, weekly, monthly and seasonal playtime rewards |
| [Dynamic Backpack](../../integration/dynamic-backpack.md) | Server-only storage with nine pages of nine item cards |
| [Player Profiles](player-profiles.md) | Multiple saved characters per account with in-place switching |
| [Vote Skip Night](vote-skip-night.md) | A player vote to skip the current night |

The plugins are server-only. Any panel or visual interface is rendered by the Server Assist client mod.
