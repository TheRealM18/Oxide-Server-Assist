# Client mods

Client-side mods are installed under the game's `Mods/` folder on the server and on every client.

| Mod | What it does |
|---|---|
| [Server Assist Mod](server-assist-mod.md) | Owns the Server Assist XUi window, renders the view protocol and sends player actions to the server |
| [QLN Pack Bootstrap](qln-pack-bootstrap.md) | Downloads, verifies, stages and applies a signed client mod pack |

Do not install two Server Assist client folders side by side, and do not install an old standalone companion client mod.
